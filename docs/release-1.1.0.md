## Изменения

- Компактные окна с достижимыми действиями при увеличенном шрифте; сохранение формы закреплено снизу.
- Возврат к прежнему месту дневника, плана, прогресса и настроек, включая ожидание асинхронной загрузки и появление нового черновика.
- Поиск и создание блюда над списком; избранное/недавнее первыми; несколько продуктов в одном сохранении с проверкой порций.
- Меню записи: изменить, повторить, перенести, удалить. Отложенное удаление можно отменить, включая удаление фото.
- Отчёт по одному показателю со столбиками, распределением калорий по приёмам, целью и раскрываемыми подробностями.
- Короткие анимации и тактильная реакция; системное отключение движения соблюдается.
- Виджет рабочего стола с показателями и быстрыми действиями; необязательное знакомство с приложением.

Предыдущие функции сохраняются. Экспорт/восстановление резервной копии, аккаунт/синхронизация, ML и автоматические рекомендации не добавлены. [Принятый объём UX](ux-v1.1.md), [подробности интерфейса](android-ui.md), [виджет](widget.md).

## Установка на телефон

1. Перенести D:/Diet/artifacts/Diet-1.1.0.apk на телефон.
2. Открыть файл и подтвердить **обновление** установленного Diet. При запросе Android разрешить установку этому файловому менеджеру.
3. Открыть Diet и проверить свой дневник. Сначала полезно пройти возврат из сна/веса, создание еды сверху и новый отчёт.
4. Для виджета открыть «Ещё → Добавить виджет» и подтвердить размещение либо выбрать Diet в списке виджетов рабочего стола.

Старый Diet перед обновлением не удалять: записи хранятся локально, удаление приложения их стирает. Версия 1.1.0 использует тот же ключ и пакет, поэтому предназначена для установки поверх 1.0.0.

Физическая проверка на S23+/Android14, OEM/Doze/cloud/D2D, TalkBack, HDR, измеренный p95/кадры/утечки и полная предметная приёмка остаются открыты. Подключение к личному телефону и изменение его данных автоматически не выполнялись.
