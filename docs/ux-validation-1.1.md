# Diet 1.1 — проверка изменений UX

Результаты ниже относятся к синтетическим данным на выделенных AVD. Личный телефон пользователя не подключался и не изменялся. Требования — [UX 1.1](ux-v1.1.md); предыдущий выпуск — [1.0.0](release-1.0.0.md).

## Сборка и автоматические проверки

- Сборка 06: debug, Android test APK, JVM и Lint PASS за 1 мин 39 с. JVM: 54 случая, 0 ошибок/пропусков. Lint: 0 ошибок, 9 неподавленных предупреждений. Двенадцать строк виджета вынесены в ресурсы без изменения размеров.
- Сборка 07: окончательные правки активного приёма пищи, понятного предела 500 позиций и сохранения списка ключей экранов после пересоздания Activity; debug/test APK/JVM PASS за 23 с.
- Отдельный native-прогон 03 на API37/16 КиБ: 13 случаев PASS за 4,906 с — FoodWorkflowTest 8, ReportMealSegmentsTest 3, WidgetIntegrationTest 2.
- Полный прогон 04 исполнил 106 случаев и выявил три сбоя. S2 с 100 тысячами записей не уложился в 10 секунд во время одновременного Lint на том же хосте; отдельный повтор без Lint прошёл с прежним лимитом (15,369 с всего, включая подготовку). Лимит не повышался.
- Два остальных сбоя были в UI-проверках: нажатие по центру графика выбирало пустой день вместо последнего дня с данными; нижняя кнопка действий еды находилась под временным сообщением сохранения. Проверки теперь нажимают последний столбик и ждут исчезновения конкретного сообщения. Бизнес-проверки точных значений, количества строк и идентификатора перенесённой записи сохранены.
- Прогон 05 подтвердил обе проверки отчётов и создание блюда над длинным каталогом; повтор еды потребовал описанного ожидания сообщения. Полный прогон окончательной сборки 07 выполнен без параллельной тяжёлой сборки: **106 случаев PASS за 165,587 с, 0 ошибок/пропусков**, включая S2 с прежним лимитом. Лог: .local-tools/test-results/android-20261115-181622.log; он остаётся локальным.

## Проверяемые гарантии

NavigationUxTest проверяет независимые позиции четырёх разделов после асинхронного возврата, сохранность позиции при повторной загрузке того же экрана, реальный редактор сна с новым черновиком над исходной карточкой и достижимость всех действий диалога при fontScale 2.

DeletionUxTest проверяет отмену до записи, revision-конфликт, сохранность нового активного редактора и нового состояния черновика. FoodWorkflowTest проверяет атомарность пакета, повтор операции, сохранение исторических значений, перенос без смены ID и порядок избранного/недавнего каталога. FoodUiTest проходит видимый путь нескольких продуктов с разными порциями и перенос результата.

ReportMealSegmentsTest сверяет сегменты с точными итогами, неполные дни, подтверждённый ноль, интервалы и более шести приёмов. ReportsUiTest проверяет один показатель на экране, закрытые по умолчанию подробности, выбор реального столбика и отклонение неверного периода. Два JVM-случая проверяют календарные границы/выбор столбика.

WidgetSummaryTest проверяет четыре состояния итогов. WidgetIntegrationTest создаёт настоящие RemoteViews при минимальном размере и шрифте 1/2, проверяет действия не меньше 48 dp и независимость сегодняшних данных от открытой даты дневника.

## Подписанный выпуск и физические границы

Установка именно нового R8 APK поверх 1.0.0, сохранность данных и действия настоящего launcher проверяются после подписи и описываются в manifest выпуска. Успех debug-инструментирования сам по себе их не доказывает.

Физические S23+/Android14, TalkBack/OEM, HDR-дисплей, Doze, облачный/D2D transport, измеренный p95/кадры/утечки и весь каталог приёмки остаются отдельными проверками. База остаётся версии 1; это обновление APK не является схемной миграцией 1→2.
