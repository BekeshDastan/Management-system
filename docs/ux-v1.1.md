# Diet1.1 — согласованное улучшение ежедневных сценариев

Пользователь проверил1.0.0 на телефоне и сообщил об обрезанной кнопке выхода, недоступном без прокрутки создании блюда и потере позиции при возврате. Принял полную переработку отчёта по приложенному примеру, анимации и все дополнительные предложения. Ниже требования нового выпуска; результат каждой проверки фиксируется после исполнения.

## Принято

1. Компактные адаптивные диалоги: все действия доступны при большом шрифте/клавиатуре/малой высоте. Выход: продолжить, оставить черновик, удалить черновик. Технические пояснения фото доступны по запросу.
2. Отдельно сохраняются позиция, выбранная дата/период, поиск/фильтры/раскрытия каждого экрана. Возврат из сна/веса/редактора/детали не сбрасывает родителя наверх; нижние вкладки независимы. Загрузка данных при возврате не уничтожает позицию.
3. Закреплённые поиск/создание продукта или рецепта и доступное добавление. Недавние/избранное под рукой; возможность выбрать несколько продуктов, изменить количества и сохранить весь состав одной транзакцией. Черновик не считается съеденной едой.
4. Отчёт: период→питание/вес/сон→главное число→столбчатый график→сворачиваемые детали. В питании переключатель4нутриентов, калории с распределением по приёмам и пунктиром цели. Нажатие столбика показывает день/значения/переход. Missing/partial/confirmedzero, N/Q и исторические цели сохраняют прежний точный смысл.
5. Короткие переходы, раскрытия, реакция на сохранение/нажатия, тактильный отклик; системное уменьшение движения соблюдается. Отступы/контраст/размер кнопок едины, без чрезмерных пустот.
6. Отмена удаления: после подтверждения появляется доступная плашка «Отменить» до отложенного удаления. До истечения окна данные остаются на месте; уход процесса безопасно отменяет ещё не совершённое удаление. Завершённая запись/ошибка удаления не скрывается анимацией.
7. Быстрые действия записи: изменить порцию, повторить, перенести в другой приём пищи с сохранением исторического снимка и контроля revision.
8. Виджет Android: сегодняшние показатели и быстрый переход к добавлению еды/веса/сна, корректные пропуски/полнота, локальное обновление.
9. Необязательное короткое знакомство с основными действиями, доступное повторно из «Ещё».

## Проверки выпуска

- Реальные диалоги320dp/font2, landscape/IME: все действия видны либо достижимы прокруткой, никакого отрезанного последнего действия.
- Прокрутить каждую вкладку, открыть/закрыть редактор, сменить вкладки; сравнить позицию/фильтры/раскрытия. Отдельно проверить возвращающийся асинхронный список.
- Длинный каталог: создание доступно сразу; пакет продуктов сохраняется целиком/ровно один раз, невалидная строка не даёт половинного результата; snapshot/повтор/перенос/undo не искажают историю.
- Отчёт: один выбранный показатель; точные значения/цели, пропуски и незавершённые дни;7/30/90/месяц/год/custom, bounded большие периоды, доступный выбор столбца.
- Виджет: добавление в launcher, изменение данных, смена даты, быстрые действия, пустой/неполный день; ограничения OEM отмечаются честно.
- Обновление поверх1.0.0 тем же ключом, новый versionCode; сохранность еды, измерений, фото, целей и raw-черновиков.
- Исходные фото пользователя остаются вне репозитория; отчёт не содержит реальных медицинских записей.

Реализация и наблюдённые проверки: [интерфейс Android](android-ui.md#изменения-интерфейса-11), [проверка UX 1.1](ux-validation-1.1.md). [Подписанный выпуск1.1.0](release-1.1.0.md) проверен установкой и обновлением на выделенных29/37; физическая приёмка остаётся отдельной.
