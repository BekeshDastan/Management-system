## TECH-003/004: числовой и постоянный контракт

По текущему поручению **документальная часть определена**, фактическая реализация/испытания не начаты:

- [numeric-contract](numeric-contract.md): ввод КБЖУ/количества до 6 знаков в micro INTEGER, вес/рост в сотых, сон в целых минутах; точные p/q BigInteger для питания/снимков и HALF_UP только при показе. Технические диапазоны, 500 строк на операцию, даты 1900–9999, Unicode 15.1/textKeyVersion=1; это не медицинские нормы.
- [storage-model](storage-model.md): логические сущности, встроенные независимые снимки, PK/FK/индексы/архив, одна атомарная граница Room и отдельная DataStore для visual-групп/их drafts/tokens. WAL/FK/FULL выбраны планово; schema v1 не создана.
- [migrations](migrations.md): версии и пути каждого будущего выпуска, schema export/синтетические фикстуры, без destructive fallback/downgrade, пересчёта истории или обещания отката подтверждённой миграции.
- [drafts](drafts.md): raw/последний durable checkpoint/факт различаются; receipt-first возвращает ранее выполненный результат без нового сохранения. Goal timeline revision, group revision и двухфазные ordinal предотвращают описанные конфликты.

Публикации предыдущего поручения TECH-003/004, remote SHA после каждого push проверен: f31f1eff4048726e4bd11e9c788a2d2feed6b19d — числа/NC; f4bbae4eef1d43fa01f47a692c61c90af5da6232 — миграции; 64955751ec1d7c82eec47aaaec2b2a2e0c6e4fd4 — черновики/ST; 5c5abbbd29e721810d4aa5dd7dbcb4b40b3abae6 — модель. Интеграция ТЗ/сценариев/плана/реестра опубликована 135a15dd373e1cb1e192186125ce63c7abf763a4, remote SHA подтверждён; после неё папка была чистой. Завершающая журнальная запись фиксирует результаты, актуальный HEAD сверять по Git.

## TECH-005/006: фото, память и системное исключение

По текущему поручению **документальный выбор выполнен**, без Android-кода/файлов/испытаний:

- [photo-processing](photo-processing.md): single/multiple по freeSlots, fallback/recheck, временный foreground URI, bounded stream, 32768px/64M source guards; ImageDecoder/EXIF8, JPEG85/sRGB/без исходных метаданных, длинная≤2048. Оригинал не архивируется. Адаптивный B по единому контракту обработки, live allocation registry, один тяжёлый native job; реальные codec/native peaks не доказаны.
- [media-storage](media-storage.md): CE noBackupFilesDir/diet, immutable master до draft refs/факта, bounded JPEG/temp cleanup, весь batch одним checkpoint; pre-Ready kill требует перевыбора, Ready восстанавливает draft. Отдельная media revision/generation, receipt-first Save, tombstone/leases GC; нет file move после fact commit.
- [system-backup-policy](system-backup-policy.md): полное inventory, actual custom Room/DataStore paths, явный allowBackup=false и legacy/extraction rules с исключением всех9 domains, отдельно cloud/D2D. Нет backup UI/экспорта/восстановления. OEM/новые транспорты/старые копии не покрываются универсальным обещанием.
- PH-001–016/BP-001–008 назначены [матрице](android-test-matrix.md); исходные144 строки неизменны. Арифметика профилей/дискового payload и независимые review пройдены; это не Android-тесты.

Публикации, remote SHA сверялся после каждого push: 79956deb3eab8643ba3d49abf7489487bcfbee81 — policy; 5e1754597e121fc5ccc6c5771057dbf7fcc735b7 — processing; 20a79e139f323c807e8d8bb435b8b4036716e2ad — lifecycle/согласование хранения; e55d04911a0a78c6b6d7a8b19af2b989a4810577 — PH/BP/матрица. Интеграция опубликована aaf3b74bd9b6a4c3a35c5b692b5a8d1005ec602e, remote SHA подтверждён, после неё рабочая папка чистая. Завершающая журнальная запись публикуется отдельно; актуальный HEAD смотреть по Git.

## Физический профиль и открытые проверки

Со слов пользователя: Samsung S23+, Android 17, RAM 8 ГБ; самый старый Android у близких — 14. В последующем ответе уточнено: около 250 ГБ — свободное место, первый тестовый APK удобно открыть файлом на телефоне. Общая ёмкость накопителя, модель близких и One UI не сообщены. Устройство/место/установка не проверялись; перед испытанием свободное место фиксируется заново. Физические Android 10–13 не названы.

**TECH-001:** SDK/документальная матрица определены; способ первой установки выбран, недостающие физические поля и диагностика уточняются до испытаний; установка ещё не проверена. **TECH-002:** документальный выбор версий выполнен; сборочная проверка первым шагом только после отдельного разрешения на код, до функционального этапа 1. Не требовать APK до появления проекта.

Read-only проверка PC ранее была ограничена PATH/стандартными каталогами; сейчас дополнительно подтверждены 64-битная Windows/AMD64. Studio/SDK/JDK не установлены этим сеансом; среда и аппаратное ускорение не объявлены готовыми.

## Принятый полный состав

Офлайн без аккаунта/рекламы: профиль, продукты/рецепты/категории, питание/копирование/исправление, ручные цели с датами, вес/суммарный сон, календарь, сворачиваемые отчёты и подробные графики, игровые имена/уровни, фото/настроение/заметки/лента, поиск, шаблоны, отдельный план питания, быстрые порции, главная/оформление и реальные напоминания.

Ранний APK ядра в плане — промежуточный срез, не сокращение полного v0.4. Сохранение после restart/reboot, миграции/черновики/идемпотентность, собственные локальные фото и системные уведомления — требования Android, а не доказанные возможности HTML.

Резервные копии/восстановление исключены (FR-016); системные исключения Auto Backup/D2D проверяются как приватность, не новая функция. Аккаунт/синхронизация (FR-002) и расчётные рекомендации (FR-004) отложены. Не переносить демонстрационный текст КБЖУ в реальный алгоритм без проверки формулы/области применения.
