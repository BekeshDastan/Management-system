- Документировать каждое существенное изменение, решение, проверку и блокер в work-log.md.

- ТЗ в целом остаётся черновиком: формула КБЖУ, детали данных, точные поля UX и стек ещё требуют решений. Kotlin/Compose/Room — предложение.

## Состояние Git и доступа

Подготовленная документация опубликована агентом: `007742e` — `docs: establish Diet planning baseline`. После push удалённая main проверена через git ls-remote: полный SHA `007742e417e5929e60f1c2b5f244375d9c66a9aa`. Более поздние коммиты проверять по истории и удалённой ветке; эта отметка не является автоматически обновляемым указателем HEAD.

В этой сессии обычная изоляция по-прежнему блокирует запись в .git и сетевой Git, но штатный механизм require_escalated доступен. Через него агент успешно выполнил git add, commit, push и проверку удалённого SHA. Настройка автора уже имелась; изменения ACL, защиты или учётных данных не потребовались.

В новом чате сначала проверять актуальные права и состояние репозитория. При ограничении использовать штатный механизм разрешений; не обходить sandbox и не менять защиту/ACL. Старые ошибки и диагностика сохранены в журнале как история, а не действующий блокер публикации.
