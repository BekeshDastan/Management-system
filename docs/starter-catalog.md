# Diet — стартовый каталог Android v1

**Состояние 15 ноября 2026:** подготовлены60позиций/10категорий и встроены в APK без обращения к API. Это усреднённые справочные продукты, не значения конкретных брендов и не медицинские рекомендации. Все единицы —100г съедобной части: мл не приравниваются к граммам, масса сухого и готового продукта не смешивается.

Источник — фиксированный [USDA FoodData Central SR Legacy April2018 CSV](https://fdc.nal.usda.gov/download-datasets/). Данные [public domain/CC0](https://fdc.nal.usda.gov/api-guide/#licensing); API-ключ и уведомление USDA не нужны для включения публичного скачиваемого набора. Приложение не имеет INTERNET. Переводы на русский локальные; исходные English description/FDC ID/NDB сохранены рядом для проверки формы продукта.

## Воспроизведение и проверка

- [selection](../scripts/starter-selection.json) фиксирует60FDC/NDB, точные English description и русские названия.
- [prepare_starter_catalog.py](../scripts/prepare_starter_catalog.py) скачивает официальный архив в игнорируемую .local-tools, проверяет SHA256, уникальность, data_type, соответствие FDC↔NDB↔description и nutrient units.
- Исходный ZIP SHA256: b80817294b8850530aaedf2e515c02593b1824f763a0ff356e5c2081643e6fd0.
- Nutrient IDs:1008 Energy/KCAL,1003 Protein/G,1004 Total lipid/G,1005 Carbohydrate/G. Отсутствующее значение не заменяется нулём; в выбранных строках все240values присутствуют.
- Decimal×1000000 сохраняется как целое micros без float/предварительного округления. Ккал не пересчитываются из БЖУ4/9/4, поскольку используется опубликованное USDA Energy.
- [starter_catalog.json](../app/src/main/assets/starter_catalog.json) format1, детерминированные UUID и LF на всех ОС. SHA256 текущих bytes: 4f857d9e7369bc6b05cbcd0402d2ac9348464275fce90a2da767a09e1001844d.
- Команда: python scripts/prepare_starter_catalog.py. Проверка всех60/240values независимым reviewer против CSV и Fraction для80г пройдена. Это не поверка лабораторной точности источника.

## Установка и обновление

[StarterCatalog](../app/src/main/java/app/diet/catalog/StarterCatalog.kt) сначала проверяет применённый seedV1, затем читает asset; наполнение60строк+категорий+receipt атомарно. После первого успешного seed новый APK не перезаписывает пользовательские изменения и не возвращает удалённые продукты. Изменение bytes/перевода manifest само по себе не блокирует открытие старого дневника; будущая корректировка каталога потребует отдельной явной миграции.

Происхождение хранится в sourceFdcId/sourceDescription/sourceRelease/sourceVerifiedRevision. После пользовательской правки origin сохраняется, но revision уже не равна verified revision: запись не выдаётся за неизменённую исходную. Факт еды всегда хранит собственный frozen снимок.

Repository regression изменённого manifest/удаления/повтора выполнена API29 PASS; integration настоящего asset/reopen проверяется отдельно. Отсутствие настоящего устройства не подменяется инструментальным тестом.
