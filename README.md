## Что войдёт в приложение

Офлайн без регистрации и рекламы: профиль, собственные продукты/рецепты, питание с историей/копированием, ручные цели по датам, вес/сон, календарь, сворачиваемые отчёты и графики, игровые названия/уровни, фото/заметки/настроение и фотолента, поиск, шаблоны, план питания, быстрые порции, настраиваемая главная/оформление и реальные напоминания.

Полный релиз сохраняет весь принятый объём. Раннее устанавливаемое ядро — только промежуточная проверка. Резервные копии и восстановление исключены пользователем. Аккаунт/синхронизация и расчётные рекомендации отложены; Kotlin/Compose/Room выбраны пользователем, точные совместимые версии ещё предстоит закрепить.

Документальный этап 0 продолжается: выбраны Kotlin + Jetpack Compose + Room и минимум Android 10 / API 29. Профиль S23+ получен со слов пользователя, у близких самый старый названный Android — 14. Модель близких, target/compile SDK, точные версии и полная матрица ещё открыты; TECH-001/002 целиком не закрыты. Установки и код не выполняются.

## Порядок работы

1. Использовать ТЗ, правила данных и сценарии как единую базу, каталог проверок — как ожидаемый результат.
2. До создания Android-проекта завершить конфигурацию выбранного стека/SDK и матрицу устройств, затем закрыть инженерные ворота зависимых этапов.
3. После отдельного запроса пользователя на реализацию выполнять план небольшими законченными сценариями. Сейчас разрешены только документы.
4. Каждую правку проверять, документировать, отдельно коммитить/push и сверять remote SHA. Локальный файл не считать опубликованным изменением.

## Посмотреть макет

Открыть [docs/prototype/index.html](docs/prototype/index.html), в старой вкладке F5 → «Полный пример». Нужна вся папка prototype с локальными JS/CSS/assets; сервер и интернет не нужны. В макете данные/фото/настройки исчезают при перезагрузке. Это ограничение демонстрации; приложение должно сохранять их постоянно. Условные 51 продукт и фотоиллюстрации не являются достоверной пищевой базой или личными записями.
